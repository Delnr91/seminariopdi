# Verificación del Contenido Educativo

Revisión realizada el **13 de octubre de 2026**.

## Estructura y Navegación

El recorrido reúne **21 páginas: dos documentos de fundamentos y 19 lecciones temáticas**. Las 19 lecciones incluyen dos párrafos de síntesis, cuatro conceptos, las cuatro categorías de recursos globales, audio identificado como pendiente y navegación anterior/siguiente. El README enlaza cada página y atribuye la curaduría a Lattices.

Se comprobaron 132 referencias locales y los enlaces recíprocos del recorrido completo. La API de Markdown de GitHub renderizó correctamente las 21 entradas del README y tres lecciones representativas, con sus secciones, recursos y navegación.

El catálogo de datos mantiene las 19 lecciones con rutas, títulos, speakers, recursos globales y nombres de audio coherentes con los documentos. Los borradores de audio se alinearon con las síntesis; su duración se medirá al producir las grabaciones.

## Enlaces Externos

Se revisaron **87 URL únicas** del contenido y del catálogo: **84 respondieron HTTP 200**. Se contrastaron los destinos y títulos de recursos específicos, descartando referencias que no identificaban la publicación o el curso anunciado. Las comprobaciones utilizaron validación TLS y tiempos de espera acotados.

## Recursos Pendientes

**Faltan los 19 MP3**. Cada lección identifica la grabación pendiente y su nombre esperado; el [inventario de audio](assets/audio/README.md) es coherente con esas rutas. ## Alcance

La revisión comprueba estructura, navegación, catálogo y referencias. Las síntesis son análisis educativo complementario, no transcripciones de las charlas. Las herramientas y perfiles enlazados no se presentan como certificados de conformidad; las prácticas que requieren servicios de pago o licencias indican ese posible coste.
